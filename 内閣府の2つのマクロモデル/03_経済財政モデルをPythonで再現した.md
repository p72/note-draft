この記事では、公表されている資料集から2026年度版のモデルを Python で組み立て直した結果を紹介する。コードと計算結果は GitHub で公開している。

## 経済財政モデルとは

経済財政モデルは、内閣府の計量分析室が作っている中長期のマクロ計量モデルである。中長期試算のほか、経済財政諮問会議に出す各種の試算に使われる。

2026年度版の資料集によると、方程式は全部で3,253本あり、次の4つのブロックからなる。

- **人口構造・労働供給**：84本。年齢・性別ごとの労働力人口、就業者数、雇用者数など
- **マクロ経済**：291本。需要項目、物価、賃金、金利、為替、分配など
- **財政**：1,711本。国の一般会計、地方財政計画、地方の普通会計、国債・地方債の発行年度別・年限別の残高と利払費など（うち国債・地方債が1,293本）
- **社会保障**：1,167本。年金、医療（制度別・年齢別）、介護（年齢別・要介護度別・サービス別）など

方程式の大部分は定義式や会計上の関係で、統計的に推計された式は50本にとどまる。マクロ経済と財政・社会保障を会計の単位まで一体で解く点が、このモデルの特徴である。ESRI の短期モデルとの違いは、このシリーズの[01の記事](01_経済財政モデルとESRI短期モデルは何が違うのか.md)に書いた。

## 何をどこまで再現したか

### 作り方

- **方程式**：資料集の方程式リスト（PDF）からテキストを取り出し、EViews 形式の式を Python の関数に自動で変換した。年齢・性別、制度、発行年度などの「ひな形」で書かれた式は、区分ごとに展開した。
- **データ**：2024年度を出発点にした。マクロ経済は国民経済計算（2024年度年次推計）と労働力調査、財政は財務省の決算、総務省の地方財政計画・普通会計決算・地方財政白書から取った。
- **標準ケース**：各式の誤差項（アドファクター）を標準経路で式が成り立つように決め、ショック後は固定して標準経路からの乖離を計算する。移植版・calibrated の主要乗数には、中長期試算の成長移行ケースの再現経路を使う。感応度分析には、各ケースの平均的な姿に近い一定成長の経路を使う。
- **解き方**：毎年度、すべての式を同時に満たす値を、式を1本ずつ解く反復計算と、同時に解く必要のある部分のニュートン法で求める。

### 原典どおりにした部分

- マクロ経済・人口ブロックの式（faithful モード。calibrated の修正は後述）
- 財政ブロックの会計部分（国の一般会計、公共事業関係特別会計、地方財政計画、交付税特会、地方の普通会計など、約250本）
- 普通国債の発行年度×年限（1・2・3・5・10・20・30・40年）の積み上げ。2025年度末に残っている国債557銘柄の残高・利率・償還日は、財務省の「普通国債の銘柄別現在高」と「国債の入札結果」から取った
- 地方債・臨時財政対策債の発行年度別の積み上げ（20年の元利均等償還）
- 社会保障ブロックの年金（83本）とその他（雇用保険・社会扶助、10本）。値は公的年金財政状況報告などの統計から取った
- 医療・介護の制度ごとの財政の仕組み（前期高齢者の財政調整、後期高齢者支援金、公費負担、保険料）

### 原典と違う扱いにした部分

- **医療・介護の年齢別・要介護度別の積み上げ（約940本）**：「基準年度の給付費 × 診療報酬・介護報酬の改定率で伸びる費用の指数」にまとめた。乗数を計算するショックでは人口や加入者数が変わらず、どの年齢区分の一人当たり費用も同じ改定率で伸びるので、まとめても給付費の動きは同じになる。人口が変わるシナリオを計算するには、展開が必要になる。
- **年金特例国債・復興債・GX経済移行債・半導体・AI債**：発行年度別の積み上げは移植していない。残高は合わせて約10兆円である。
- **資料に値が載っていないパラメータ**：診療報酬改定率の賃金と物価の重みや、既発の地方債の償還予定などは推定した。

また、公表乗数表に合わせるための修正を入れた「calibrated」と、資料のとおりにした「faithful」の2つのモードを切り替えられるようにした。calibrated ではコールレート式の `0.246378*d(M_TAYLOR)` の項を外す。簡略版ではさらに、地方の収支のうち地方債に回る割合と、法人課税が翌年度に効く割合も調整している。移植版と簡略版では、修正の範囲が異なる。

## 精度1：公表乗数表との比較

資料集の主要乗数表には、政府支出の一時的・継続的な拡大、法人税・所得税の増税、消費税率の引き上げ、TFP上昇率の引き上げ、原油価格の上昇、短期金利の引き上げの8ケースについて、1〜5年目の標準ケースからの乖離が載っている。政府支出の追加分は、国・地方の政府消費と公共投資に配分する。

### 標準経路と計算時期の見直し

資料集は、GDPギャップがゼロのまま推移する外挿期間の標準ケースと、ショックを与えた経路を比べるとしている。初期の実装は2026年度からショックを与えていたが、この時期は地方に財源不足があり、収支の変化が地方債の増減に結び付きやすかった。

現在の移植版・calibrated は、成長移行ケースの再現経路の2031〜2035年度を使う。この時期には地方の財源不足がなく、収支の変化の多くを積立金で受け止めるため、公債等残高比の反応が小さくなる。計算時期と標準経路を変えることで、公債等残高比のRMSEは0.843から0.369%ptへ縮んだ（後述の法人税ケースの修正後は0.171%pt）。

ただし、**現在の標準経路のGDPギャップは約0.6%でほぼ一定であり、公表条件のゼロとは一致していない。** また、faithful と簡略版は従来の標準ケースの2026年度から計算している。モード間の誤差の違いには、式の変更だけでなく計算条件の違いも含まれる。

### 最新の結果

公表値とのRMSEは次のとおり（財政ブロック移植版・calibrated）。通常は8ケース×5年の40点、コールレートは金利を外生的に引き上げるケースを除く35点で計算した。RMSEは誤差の代表的な大きさであり、各点の誤差の上限ではない。

| 指標 | RMSE（%pt） |
|---|---:|
| 実質GDP | 0.056 |
| 消費者物価 | 0.025 |
| コールレート（金利ケースを除く） | 0.019 |
| 基礎的財政収支（国・地方、対GDP比） | 0.034 |
| 公債等残高（国・地方、対GDP比） | 0.171 |

政府支出を継続的に実質GDPの1%増やすケースでは、実質GDPの乖離は1年目がモデル1.08%／公表1.08%、5年目が0.44%／0.41%である。

## 精度2：中長期試算の感応度分析

[中長期試算（2026年1月）](https://www5.cao.go.jp/keizai3/econome/r8chuuchouki2601.pdf)の「リスク・不確実性」の節には、3つの感応度分析が載っている。いずれも2027年度以降、ほかの前提を変えずにショックを与えた場合の姿である。

- TFP上昇率が過去投影ケースより0.5%pt低い（図19）
- 長期金利が0.5%pt高い（図20）
- 政府支出が毎年、名目GDPの0.5%多い（図21）

資料の感応度分析は、2026年度版ではなく「経済財政モデル（2018年度版）」の主要乗数表を当てはめて作られている。再現モデルで同じショックを直接計算し、比べた。標準ケースは、過去投影ケースと成長移行ケースの2027〜2035年度の平均的な姿（実質成長率、GDPデフレーター、長期金利）に近い一定成長の経路にした。

![中長期試算の感応度分析の再現](https://raw.githubusercontent.com/p72/cao-economic-fiscal-model/03ac7a0083c7aa3957ade28a1c55ea745050483d/output/chuuchouki_sensitivity.png)

2035年度の乖離は次のとおりである（資料 → 再現モデル）。

- **TFP上昇率−0.5%pt**：潜在成長率 −0.9%pt → −0.8%pt、基礎的財政収支 −1.0%pt → −1.2%pt、公債等残高比 +9.4%pt → +12.1%pt
- **長期金利+0.5%pt**：公債等残高比 +3.2%pt → +3.6%pt（過去投影ケース対比）、+3.2%pt → +3.4%pt（成長移行ケース対比）
- **政府支出+名目GDPの0.5%**：基礎的財政収支 −0.5%pt → −0.5%pt（過去投影ケース対比）、−0.5%pt → −0.5%pt（成長移行ケース対比）

金利と政府支出のケースはおおむね近い。TFP低下のケースは方向は合うが、2035年度の公債等残高比の上昇が公表値より2.7%pt大きい。比較対象は2018年度版の乗数を使った試算なので、2026年度版の主要乗数表の再現とは別の検証である。

公表試算は同じ2018年度版の乗数表を使っており、2035年度の金利ケースの公債等残高比の乖離は、両ケースとも丸め後で+3.2%ptになる。ただし、公表された各年度の数値を引き算すると、ケース間の乖離は必ずしも完全には一致しない。再現モデルでは標準経路の違いによって反応が変わり、金利ケースの2035年度の残高比は、過去投影対比で+3.6%pt、成長移行対比で+3.4%ptになる。

## 精度3：中長期試算の主要計数表

中長期試算の本体は、2035年度までの経済と財政の姿である。計数表「1.主要計数表」（冊子32ページ、PDFの35ページ目）には、過去投影・成長移行・高成長実現の3つのケースについて、潜在成長率、実質・名目GDP成長率、賃金、失業率、物価、長期金利、基礎的財政収支、公債等残高（いずれも国・地方）の年度ごとの値が載っている。これを再現モデルで作り直した。

### 方法

出発点は2024年度の実績である。人口は国立社会保障・人口問題研究所の将来推計人口（令和5年推計、出生中位・死亡中位）を使い、労働参加率は、公表資料の2024年度63.4%から2035年度の過去投影65.7%、成長移行・高成長実現66.9%への上昇幅を、モデルの2024年度の率に加える。公表値の水準そのものへの一致を強制する実装ではない。TFP上昇率は過去投影で0.6%とし、成長移行1.1%、高成長実現1.4%には2029年度に到達するとした。世界経済成長率は2027〜2030年度に2.8%から2.5%、以降2.5%、原油は2025・2026年度が1バレル68.1ドル、2027年度以降が73.7ドルとする。世界経済の年ごとの経路などには推定が含まれる。

現在の再現は、次の条件を与えて財政のつながりを確かめる方法である。

- **マクロ主要項目は全期間、公表値に合わせる。** 潜在成長率、実質GDP成長率、消費者物価、GDPデフレーター、失業率、賃金、名目長期金利を、対応する式のアドファクターで合わせる。短期金利は長期金利との差を2024年度の実績の0.87%ptに保つ。
- **財政の合わせ方は期間によって異なる。** 2025・2026年度は国・地方のPB、国の税収、公債等残高比を公表値に合わせる。国のPB対象経費と地方の一般歳出を目標にするのは2027年度以降である。2026年度に残った差（過去の補正予算で積んだ基金からの支出とみなす）は毎年3割ずつ残るとし、国の分はその年の国債発行にならないよう、SNAの支出だけに加える。国の利払費、地方の税収、地方交付税等は2025〜2035年度を通して公表値を目標にする。ただし、地方の項目にはモデルと公表資料の定義差を埋める調整があり、モデルの原系列をそのまま一致させるわけではない。2027年度以降は国のその他収入の2026年度からの増減も合わせる。高成長実現ケースの扱いは後述する。
- **その条件のもとで、SNAベースのPBと公債等残高を計算する。** ただし2025・2026年度は、PBと公債等残高比も公表値に合わせる。
- **高成長実現ケースには追加の仮定がある。** 公表資料に財政の詳細計数表がないため、成長移行ケースの歳出等を賃金上昇率の差の半分で延ばし、利払費には成長移行ケースで決めたアドファクターを使う。公表側は2018年度版の乗数表を成長移行ケースに足しているため、作り方も異なる。

したがって、以下のマクロ項目の一致は独立した再現精度を示すものではない。**公表された経済・予算の経路を条件として、2027年度以降のPBや債務残高がどこまで合うか**が、この比較の中心になる。

旧版では過去投影ケースの公債等残高比が2035年度に約9%pt低かったが、現在は0.3%pt低い。これは前提・計算方法の変更と不具合修正を合わせた結果であり、同じ条件のまま誤差だけが縮んだわけではない。

### 何を修正したか、どこに差が残るか

地方の黒字は、すべてが債務の削減になるわけではない。公表資料の注26も、一部を償還に充て、残りは将来の歳出のための積立金とする扱いを示している。実装では地方債関連の入力ミスを直し、臨時財政対策債がマイナスにならないようにした。

さらに、主要計数表の再現では次を修正した。

- 2024年度の地方債の「決算÷計画」の倍率約1.4を将来も掛け続けていたため、1を上回る部分が2027年度以降は毎年3割ずつ残るようにした。
- 交付税特会借入金残高の積み上げに、名目成長の経路へ合わせるアドファクターが入っていたため、これをゼロにした。
- 伸び率・比率の変数、地方の計画年度ダミー、交付税率を名目額と同じように伸ばしていた不具合を直した。
- 2026年度に残る基金からの支出の影響は、翌年度以降に毎年3割ずつ残るとした。当初はこれを国の予算の歳出に加えていたため、その年の国債発行が増え、公債等残高比が2027年度から0.4〜0.5%pt高く出ていた。基金は過去に発行した国債で積んだものなので、SNAの支出だけに加えるよう改め、2035年度までの残高比の最大の差は過去投影1.0→0.3%pt、成長移行1.2→0.6%pt、高成長実現4.0→3.5%ptになった。国のその他収入は、定義の違いがあるため水準全体ではなく2026年度からの増減を合わせた。

現在は、成長移行ケースの2035年度のPBが公表値より約0.2%pt高く、高成長実現ケースの公債等残高比が約3.5%pt高い。前者では国の歳出内訳とSNAへの対応、後者では公表試算との計算方法の違いと利払費の動きが課題として残る。モデルの歳出内訳は2024年度決算を基にしているため、2026年度当初予算を起点とする公表試算との対応をさらに詰める必要がある。

## 資料集を読んで分かったこと

モデルを組み立てる過程で、資料集について次のことが分かった。

- **方程式リストに欠落と誤植がある。** 地方財政計画の歳出総額（`ZP_LGEXTOTAL`）は見出しだけで式がなく、別の変数の式が載っている。括弧の閉じ忘れが3本ある。雇用保険料の式は、単位の違う量（賃金と雇用者数）を足す形になっており、積の誤植と判断した。年金の改定率の式4本は、PDF の行の折り返しで式が途切れており、注記の続きをつないで復元した。
- **国債の残高・償還額・利払費の合計式は、モデルで発行する令和7年度以降の分だけを並べている。** 一方、変数リストには平成11年度〜令和6年度に発行した既発債の変数もある。普通国債の残高は1,000兆円を超えるので、合計には既発債も含まれているはずである。
- **実質GDPと需要項目の乗数の対応には、説明しきれていない差がある。** 原油価格のケースでは約+0.12%pt、金利のケースでは約−0.1%pt、TFPのケースでは約+0.12%pt食い違う。これらは再現モデル側の構成比等を使った照合で見つかった差である。公表側の標準経路の構成比や実質値の集計方法を確認できていないため、この差だけで公表表の誤りとは断定できない。

## 自分で動かすには

計算は誰でも手元で再現できる。Python のコードを実行できる AI を使えば、プログラムを書かなくても動かせる。方法は2つある。

### 1. パソコンで動かす

Python 3.11以上を入れ、リポジトリをダウンロードしたフォルダで次の2行を実行する。資料集の PDF と国民経済計算の表は、内閣府のサイトから自動でダウンロードされる。標準経路の作成を含む計算時間の目安は40〜50分で、結果は `output` フォルダにできる。

> python -m pip install -r requirements.txt
> python run_all.py

Claude Code のようにパソコンの中でコードを実行できる AI に、リポジトリの URL を渡して「README の『はじめての方へ』のとおりに動かして」と頼んでもよい。

### 2. クラウドの環境で動かす

Claude Code on the web や ChatGPT の Codex は、GitHub のリポジトリをクラウド上の Linux 環境に取り込んで、そこでコードを実行する。パソコンに Python を入れる必要はない。

内閣府のサイトへ接続できるかは、サービスや環境のネットワーク設定による。接続が制限されている場合は設定が必要になる。Claude Code on the web では、環境のネットワーク設定に `www5.cao.go.jp` と `www.esri.cao.go.jp` の2つを加える。Codex では、インターネットにつながるセットアップスクリプトの段階で、資料とデータのダウンロードを済ませる。具体的な設定は README に書いた。

ChatGPT や Claude のチャット画面にも Python を実行する機能があるが、外部のサイトにつながらないことが多く、資料とデータのダウンロードで止まるので、おすすめしない。

主要計数表の再現まで含めたすべての計算は、`python run_all.py --all` で2〜3時間かかる。

## 残る課題

公表結果の忠実な再現に向け、まず計算条件と残差の原因を確認する。

- faithful と calibrated の標準経路・ショック年度をそろえて比較する。GDPギャップがゼロで推移するという公表条件にも合わせ、式の変更と標準経路の変更の効果を分ける。
- 法人税ケースの公債等残高比に残る差（0.57%pt）を、税収、財政収支、国債・地方債発行、償還、積立金、名目GDPに分解して調べる。
- 既発地方債の償還・利払い予定を、現在の平均14年償還という推定から統計に置き換える。
- 主要計数表では、国の歳出内訳とSNAへの対応、高成長実現ケースの利払費と公表試算の作り方の違いを詰める。
- 医療・介護の年齢別・要介護度別の積み上げを展開し、人口が変わるシナリオにも対応する。
- 年金特例国債・復興債・GX経済移行債・半導体・AI債の発行年度別の積み上げを移植する。

構造の移植に関する作業項目は[忠実移植の計画書](https://github.com/p72/cao-economic-fiscal-model/tree/03ac7a0083c7aa3957ade28a1c55ea745050483d/docs/plan_faithful_port.md)にまとめている。上の計算条件の統一と残差分解は、今後の検証課題であり、この記事の数値にはまだ反映していない。
