## 原著との対応
原著：Dupor & Hogan (2025), Working Paper 2025-007A、第2節・付録A～D。
https://s3.amazonaws.com/real.stlouisfed.org/wp/2025/2025-007.pdf

| 項目 | 原著 | 現在の日本版 |
|---|---|---|
| 変数 | 価格・実質数量の月次対数差 | CPI・CPIで実質化した家計支出の月次対数差 |
| ラグ | 12 | 12 |
| 推計期間 | パンデミック分析は1990～2023年 | 2000年1月～2026年9月を予定 |
| 推計係数 | 固定サンプル | 固定サンプル |
| 分類 | 価格・数量残差の積が負なら供給、それ以外は需要 | 同じ |
| 動学効果 | 残差ベクトル全体へのMA係数 | 数学的に同値なVAR再帰 |
| ウェイト | 当月・前月の名目支出シェアの幾何平均 | 同じ式。ただし日本の家計調査支出 |
| 12か月寄与 | 月次寄与の移動合計 | 同じ |
| 季節性 | 米国PCEの公表系列 | 未調整系列に月ダミーを追加する日本向け仕様 |
| 初期条件 | 式(2)のドリフトに関わるが実装詳細は原著本文だけでは確定できない | 最初のラグ期間の観測値を全てドリフトに置く有限標本規約 |
| 公式指数との一致 | 品目集計と公式指数は厳密には一致しない | 差をトレンドへ混ぜず別に検証する予定 |

ドリフトは定数・月ダミー・初期値から生成する無ショック経路である。純粋な長期期待や、任意の期間平均と同一視しない。
完全な著者コード再現と呼べる段階ではない。

現行ダッシュボード：
https://www.stlouisfed.org/research/pce-inflation-drivers
2026-11-25更新ページでは、トレンドを1990～99年および2022～23年の平均インフレと調整差で説明している。調整差によって表示成分は公式PCEへ一致する。原著の式(2)を実装するだけで、この現行表示仕様の完全再現とはならない。対象期間平均をモデルのどこに入れるかなど、ページだけでは確定できない詳細は未検証。

## 実行した検証
Python 3.14.0 / numpy 2.3.4 / pandas 2.3.3 / requests 2.32.5 / matplotlib 3.10.8。

- 既存self-test：合格。
- 独立に構築したMA係数の畳み込みと再帰計算を比較：ラグ1・3・6・12、全期間推計・固定した短い推計期間の8ケースで合格（絶対許容差1e-10）。
- 通信例外のトレースバックに模擬APIキーが出ないこと：合格。
- CSV読込でコードの先頭ゼロを維持し、47支出分類→45価格分類、321か月の合成パネルを構成：合格。
- 1観測の欠損を意図的に与えて拒否すること：合格。

すべて合成データによる検査であり、日本経済の実測結果ではない。安定性や分類の経済学的正しさを証明する検査でもない。

2. CPIは2026年に2025年基準へ改定されている。指定された2020年基準表が対象末月まで揃うか、取得後にメタデータと観測を確認する。2025年基準の品目コードを無確認で流用しない。
   https://www.e-stat.go.jp/api/info-cat/
3. APIレスポンスの月次以外の行、分類次元、直接数量表の対応、公式ウェイトの被覆率は未検証。完全パネル検査に失敗した際に補間・ゼロ埋めで通さない。
4. 判別不能の閾値0.1・0.15・0.3、ラグ3、5/10/15年窓、水準VAR、ローリング、季節調整の比較は未実装または未実行。現コードの5仕様だけでは依頼された感度分析を満たさない。
5. 判別不能を追加する場合、その当期残差だけでなく過去の伝播も別成分に保持する。5成分に無理に押し込めない。
6. 制度要因を分離する場合もその動学効果を別枠に残す。特定月の寄与を落とすだけでは加法整合性が壊れる。
7. 直接数量による測定誤差検証、残差自己相関、予測精度、外部指標との関係は未実施。

9. 既存Shapiro版は当月の価格変化全体を分類する。新方式の残差＋過去効果と比較するときは、同じ価格・数量・係数・ウェイトでも割当対象が違うことを説明する。
10. 日本版の指定6時点の値、2026年の需要低下、2022年供給優位の頑健性は未判定。既存記事の数値を新方式の結果として転記しない。
