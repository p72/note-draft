- [短観の物価見通し/01\_販売価格見通しの5年後6.1％は年率1.2％にすぎない](https://p72.github.io/note-draft/%E7%9F%AD%E8%A6%B3%E3%81%AE%E7%89%A9%E4%BE%A1%E8%A6%8B%E9%80%9A%E3%81%97/01_%E8%B2%A9%E5%A3%B2%E4%BE%A1%E6%A0%BC%E8%A6%8B%E9%80%9A%E3%81%97%E3%81%AE5%E5%B9%B4%E5%BE%8C6.1%EF%BC%85%E3%81%AF%E5%B9%B4%E7%8E%871.2%EF%BC%85%E3%81%AB%E3%81%99%E3%81%8E%E3%81%AA%E3%81%84.html)（[GitHub](https://github.com/p72/note-draft/blob/main/%E7%9F%AD%E8%A6%B3%E3%81%AE%E7%89%A9%E4%BE%A1%E8%A6%8B%E9%80%9A%E3%81%97/01_%E8%B2%A9%E5%A3%B2%E4%BE%A1%E6%A0%BC%E8%A6%8B%E9%80%9A%E3%81%97%E3%81%AE5%E5%B9%B4%E5%BE%8C6.1%EF%BC%85%E3%81%AF%E5%B9%B4%E7%8E%871.2%EF%BC%85%E3%81%AB%E3%81%99%E3%81%8E%E3%81%AA%E3%81%84.md)）（販売価格の見通しは「現在の水準と比べた変化率」なので、1年先・3年先・5年先を並べたグラフでは5年先が必ず上に来る。年率に直すと5年先6.1％は約1.2％で、値上げは最初の1年に集中していることを、見通しを調査時点から伸ばして実績と重ねるヘアリーチャートで示す。グラフ：`01_chart_hairy_general.png`、`01_chart_hairy_sales_all.png`、`01_chart_hairy_sales_sector.png`、作図コード：`01_plot.py`）

## 名目GDP水準目標

内閣府 経済社会総合研究所（ESRI）「短期日本経済マクロ計量モデル（2022年版）」の Python 再現（[p72/esri-short-run-macro-model](https://github.com/p72/esri-short-run-macro-model)）と、ESRI の国民経済計算（2024年度年次推計）をもとにした記事です。

- [名目GDP水準目標/01\_名目GDP水準目標なら日本の政策金利はいくらだったか](https://p72.github.io/note-draft/%E5%90%8D%E7%9B%AEGDP%E6%B0%B4%E6%BA%96%E7%9B%AE%E6%A8%99/01_%E5%90%8D%E7%9B%AEGDP%E6%B0%B4%E6%BA%96%E7%9B%AE%E6%A8%99%E3%81%AA%E3%82%89%E6%97%A5%E6%9C%AC%E3%81%AE%E6%94%BF%E7%AD%96%E9%87%91%E5%88%A9%E3%81%AF%E3%81%84%E3%81%8F%E3%82%89%E3%81%A0%E3%81%A3%E3%81%9F%E3%81%8B.html)（[GitHub](https://github.com/p72/note-draft/blob/main/%E5%90%8D%E7%9B%AEGDP%E6%B0%B4%E6%BA%96%E7%9B%AE%E6%A8%99/01_%E5%90%8D%E7%9B%AEGDP%E6%B0%B4%E6%BA%96%E7%9B%AE%E6%A8%99%E3%81%AA%E3%82%89%E6%97%A5%E6%9C%AC%E3%81%AE%E6%94%BF%E7%AD%96%E9%87%91%E5%88%A9%E3%81%AF%E3%81%84%E3%81%8F%E3%82%89%E3%81%A0%E3%81%A3%E3%81%9F%E3%81%8B.md)）（日本が2020年から名目GDPを年3%・4%・5%の経路に乗せる名目GDP水準目標（NGDPLT）を採っていたら、政策金利は何%だったかを計算した記事。年4%・5%なら政策金利は2020〜24年を通してマイナス、年3%なら2023年以降ほぼゼロに戻る。どの目標でも、2022〜23年の原油高・円安でインフレ目標ルールが4〜5%まで利上げするのと違って利上げしないことを示す。モデルに組み込むと名目GDPは押し上げられるが、目標の経路には届かない。グラフ：`01_chart_ngdplt.png`）
