- `交易条件とデフレ/01_交易損失は賃金を下げるのか.md`（グラフ：`01_chart_table.png`、`01_chart_decomp.png`）
- `交易条件とデフレ/02_CPIとGDPデフレーターの差と実質賃金.md`（OECD Economic Outlook の日本・韓国の長期データで、CPIとGDPデフレーターのギャップ、交易条件、時間当たり実質報酬、実質ULCを比べた記事。グラフ：`02_chart_gap_tot.png`、`02_chart_hourly.png`、`02_chart_realulc.png`）

- `交易条件とデフレ/04_交易条件の悪化は何で起きたのか.md`（日本銀行の輸出・輸入物価指数の類別指数から、交易条件の悪化を品目別寄与に分解した記事。電気・電子機器の品目内の交易条件は悪化しておらず、悪化の大半は資源を中心とする一次産品価格の上昇によることを示す。グラフ：`04_chart_tot_currency.png`、`04_chart_tot_electronics.png`、`04_chart_contrib.png`）
- `交易条件とデフレ/05_輸出価格は円建てで低いのかドル建てで低いのか.md`（日本銀行の輸出物価指数（円ベース・契約通貨ベース）、世界銀行の輸出単価指数、BLSの原産国別輸入物価指数（FRED）、OECDの輸出デフレーターで、日本の輸出価格の弱さが円建てとドル建てのどちらにあるかを長期推移と国際比較で検証した記事。ドル建て価格が35年間ほぼ据え置かれ、円建て価格は為替に合わせて動いてきたことを示す。グラフ：`05_chart_longterm.png`、`05_chart_relative.png`、`05_chart_unitvalue.png`、`05_chart_category.png`、`05_chart_bls.png`、`05_chart_deflator.png`、`05_chart_tot_decomp.png`、`05_chart_passthrough.png`）
- `交易条件とデフレ/06_円安の物価押し上げ効果は大きくなったか.md`（内閣府「短期日本経済マクロ計量モデル（2022年版）」の Python 再現と、日本銀行の輸入物価指数・名目実効為替レート、総務省の消費者物価指数で、「円1％安で消費者物価0.02％」という論文のモデルの結果が近年も成り立つかを検証した記事。デフレ期はほぼ0だった為替パススルーが2021年以降は約0.2に上がったことを示す。グラフ：`06_chart_passthrough.png`、`06_chart_table1.png`〜`06_chart_table4.png`）
- `交易条件とデフレ/07_交易損失は賃金を下げるのかを内閣府モデルで確かめた.md`（01 の反事実を同じモデルで試算した記事。2022年規模の交易損失を金融政策の設定を変えて解くと、どの政策でも国内物価はほとんど上がらず名目賃金が下がる「2008年型」になり、分かれ目は金利より価格転嫁と賃金の決まり方であることを示す。グラフ：`07_chart_explain1.png`〜`07_chart_explain3.png`、`07_chart_table.png`）
- `交易条件とデフレ/08_内閣府モデルは2022〜24年にデフレを予測していた.md`（モデルの誤差項を平時の平均にした事後シミュレーションで、2022〜24年の実績との差を式ごとに分解した記事。差のほぼ全部が価格転嫁の項を持たない国内物価の式から来ること、賃金は値上げに遅れて利潤に回ったことを示す。グラフ：`08_chart_expost.png`、`08_chart_table1.png`、`08_chart_table2.png`）
