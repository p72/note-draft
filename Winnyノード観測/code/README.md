# Winny 観測クライアント（観測専用）

記事「MuseがWinnyに接続してみた」で使用した、Winny ネットワークの観測用クライアントである。Python 標準ライブラリのみで動作する。

## 設計原則

- 収集するのはノード情報とキー情報（ファイル名・サイズ・ハッシュ等のメタデータ）のみであり、**ファイルの実体は送受信しない**。
- 自前のキー情報は持たず、検索は空クエリへの応答のみで参加する。
- 受付ポートは持たない（Port0）。タイプ3とクエリ経路のポート欄には固定値 7743 を申告する（待ち受けはしない。実態と異なる申告であることは PROTOCOL.md §6.2 に明記してある）。

## ファイル

- `PROTOCOL.md` — 再構成ソース（loadletter/Winny-p2p）の精読から作成したプロトコル仕様メモ
- `winny_codec.py` — RC4、ノード文字列の復号・検証、空クエリの構築
- `winny_client.py` — ハンドシェイク（接続マーカー、ハロー検証、再鍵、タイプ1〜3交換）
- `crawl.py` — フェーズ3クローラ。入口ノードに長時間接続し、ノード紹介（タイプ4）とキー情報を含むクエリ（タイプ13）を収集する。タイプ10への空クエリ応答と、30秒周期のタイプ10送信を含む。結果は `nodes.json` と `result_crawl.txt` に出力する
- `bootstrap.py` — 入口確認用。Noderef を取得し、候補へ順に接続を試して短時間観測する
- `mock_peer.py` — テスト用の模擬ノード
- `test_proto.py` / `test_crawl.py` — 自己テスト（モックとの E2E を含む）

## 使い方

前提：Python 3.12 以降。

```
python bootstrap.py   # 入口ノードの確認（30秒観測）
python crawl.py       # 本観測（既定600秒＋スノーボール）
python test_proto.py  # テスト
python test_crawl.py
```

## 同梱していないもの

入口ノードの一覧（`noderef_extra.txt` / `noderef_fallback.txt`）は同梱していない。接続先ノードのアドレスは第三者の情報であるため、公開しないという記事の方針による。利用する場合は、配布サイトから取得した Noderef や、自分で入手したノード文字列を同名ファイルとしてこのフォルダに置くこと（crawl.py はこの2ファイルを、bootstrap.py は取得失敗時の予備として `noderef_fallback.txt` を読む）。

観測ログ（nodes.json、result_crawl.txt、生の受信ダンプ）も同様の理由で同梱していない。
