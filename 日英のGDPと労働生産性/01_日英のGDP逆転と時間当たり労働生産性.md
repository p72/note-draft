# 日英のGDP逆転と時間当たり労働生産性──水準の差は広がったが、実質の伸びは日本が上回っていた

ウェブ版：[https://p72.github.io/note-draft/日英のGDPと労働生産性/01\_日英のGDP逆転と時間当たり労働生産性.html](https://p72.github.io/note-draft/%E6%97%A5%E8%8B%B1%E3%81%AEGDP%E3%81%A8%E5%8A%B4%E5%83%8D%E7%94%9F%E7%94%A3%E6%80%A7/01_%E6%97%A5%E8%8B%B1%E3%81%AEGDP%E9%80%86%E8%BB%A2%E3%81%A8%E6%99%82%E9%96%93%E5%BD%93%E3%81%9F%E3%82%8A%E5%8A%B4%E5%83%8D%E7%94%9F%E7%94%A3%E6%80%A7.html)

GitHub：[https://github.com/p72/note-draft/blob/main/日英のGDPと労働生産性/01\_日英のGDP逆転と時間当たり労働生産性.md](https://github.com/p72/note-draft/blob/main/%E6%97%A5%E8%8B%B1%E3%81%AEGDP%E3%81%A8%E5%8A%B4%E5%83%8D%E7%94%9F%E7%94%A3%E6%80%A7/01_%E6%97%A5%E8%8B%B1%E3%81%AEGDP%E9%80%86%E8%BB%A2%E3%81%A8%E6%99%82%E9%96%93%E5%BD%93%E3%81%9F%E3%82%8A%E5%8A%B4%E5%83%8D%E7%94%9F%E7%94%A3%E6%80%A7.md)

※ この記事は、IMF「World Economic Outlook」の数値（報道経由）、日本生産性本部「労働生産性の国際比較 2025」、OECD Productivity Database の公表データを使っている。

日本と英国の名目GDPが近い将来逆転するという見通しが話題になっている。ドル建ての名目GDPで日本はドイツに抜かれ、インドとの順位も入れ替わりを繰り返しており、次は英国だというわけである。

しかし、ドル建て名目GDPの順位は為替レートの動きに大きく左右される。経済規模の比較として何を測っているのかを確かめたうえで、より比較に向いた指標である時間当たり労働生産性について、OECDのデータで日本と英国、さらにG7の推移を見る。

結果を先に書くと、次のとおりである。

- ドル建て名目GDPの日英の差は小さいが、購買力平価（PPP）で換算すると日本の経済規模は英国の約1.5倍あり、順位の接近には円の実質的な減価が大きく効いている。
- 時間当たり労働生産性の水準（当年価格・当年PPP換算）では、日本はG7で最も低い。2025年は日本が約62ドル、英国が約86ドルで、日本÷英国の比は1995年の0.82から2025年の0.72に下がった。
- 一方、物価の影響を除いた実質の伸びでは、1995〜2025年の日本は年率1.18％で、英国の1.02％を上回る。G7では米国に次いで2番目である。英国は2008年以降の伸びが年率0.3％にとどまっている。
- 実質（固定価格・固定PPP）で見た日本÷英国の比は、1995年の0.69から2025年の0.73に上がっている。当年価格・当年PPPで見た比が下がったのは、実質の伸びの差ではなく、日英の生産物をどの年の価格で評価するかによる違いである。

## ドル建て名目GDPの比較は何を測っているか

話題の元になっているのは、IMFが各国の名目GDPを米ドルに換算して並べた数字である。2026年4月のIMFの見通しでは、2026年の日本は4.38兆ドル、英国は4.26兆ドルで、その差はわずかである。2025年10月の見通しでは、2030年に英国（5.20兆ドル）が日本（5.12兆ドル）を上回るとされていた。

IMFのドル換算は、各国通貨建ての名目GDPを市場の為替レートで割ったものである。そのため、円安が進めば、日本の生産量や国内の物価が変わらなくても、ドル建てのGDPは小さくなる。報道によれば、実質実効為替レートは英国が111、日本が約67で、日本の通貨は実質的に大きく減価している。

同じGDPを購買力平価で換算すると、2026年の日本は7.26兆ドル、英国は4.72兆ドルで、日本は英国の約1.5倍になる。購買力平価は各国の物価水準の違いを調整した換算レートであり、「同じものがどれだけ作られたか」に近い比較になる。ドル建て名目GDPで日英が並んだことは、生産の規模が並んだことを意味しない。

ただし、英国の人口は約6900万人で日本の約半分であり、1人当たりで見れば英国が上である。また、実質成長率は英国が日本を上回るという見通しが続いている。順位の接近を為替だけで片付けることもできない。

## 「国力」は一つの数字では比べられない

経済規模は国力の一要素にすぎない。軍事力、外交上の地位（英国は核保有国であり国連安全保障理事会の常任理事国である）、金融センターとしての地位、言語や文化の影響力、財政の余力など、国力に含まれうる要素は多い。これらを合成した指数もあるが、どの要素にどれだけの重みを置くかで順位は変わる。

比較に向いているのは、何を測るかが明確な指標である。その代表が労働生産性である。

## 労働生産性とその比較の注意点

労働生産性は、付加価値（国全体ではGDP）を労働投入量で割ったものである。日本生産性本部の「労働生産性の国際比較 2025」によれば、2024年の日本の時間当たり労働生産性は60.1ドル（購買力平価換算）で、OECD加盟38か国中28位である。

国際比較では、次の点に注意が要る。

- **分母**：就業者1人当たりか、就業1時間当たりか。短時間労働者の割合が増えると、1人当たりの生産性は下がりやすい。各国の働き方の違いをならすには時間当たりが適している。
- **換算レート**：経済全体の比較は購買力平価で換算するのが基本である。市場の為替レートで換算すると、為替の変動がそのまま入る。
- **付加価値の測り方**：サービスの質の違いはGDPに十分には反映されない。品質が高くても価格が低ければ、付加価値は低く測られる。
- **産業構成**：金融や専門サービスのように付加価値の高い産業の比重が大きい国は、全体の平均が高くなる。
- **水準と伸び率**：水準の比較は換算方法に左右されやすい。実質の伸び率の比較のほうが頑健である。

この記事では、OECD Productivity Database の就業1時間当たりGDPを使い、当年価格・当年PPPの系列で水準を、固定価格・固定PPPの系列で実質の伸びを見る。

## G7の時間当たり労働生産性

![G7の時間当たり労働生産性の推移](01_chart_g7.png)

左の図は、当年価格・当年PPPで換算した時間当たり労働生産性である。2025年の値は、米国105ドル、ドイツ103ドル、フランス96ドル、英国86ドル、イタリア80ドル、カナダ77ドル、日本62ドルである。日本は1990年以降一貫してG7で最も低い。なお、2024年の日本の値は59.9ドルで、日本生産性本部の60.1ドルとほぼ一致する。

右の図は、固定価格・固定PPPの実質系列を1995年＝100で指数化したものである。2025年の値は、米国169、日本142、英国136、ドイツ134、カナダ132、フランス129、イタリア106である。日本の実質の伸びはG7で米国に次いで2番目であり、英国やドイツを上回っている。

期間を分けて年率の伸びを見ると、日英の違いがはっきりする。

- 1995〜2007年：日本1.71％、英国2.10％
- 2007〜2019年：日本0.92％、英国0.30％
- 2019〜2025年：日本0.63％、英国0.30％
- 1995〜2025年：日本1.18％、英国1.02％

1995〜2007年は英国の伸びが日本を上回っていたが、世界金融危機以降、英国の伸びは年率0.3％にとどまっている。英国ではこの停滞が「生産性パズル」と呼ばれ、長く議論の対象になってきた。日本も伸びは鈍化しているが、英国ほどではない。

## 日英の差は広がったのか、縮まったのか

左の図だけを見ると、日英の差は広がっている。一方、右の図では日本のほうが伸びている。この食い違いを確かめるため、日本の値を英国の値で割った比を、二つの系列で比べた。

![日本の時間当たり労働生産性は英国の何倍か](01_chart_ratio.png)

当年価格・当年PPPで見た比（赤）は、1995年の0.82から2025年の0.72に下がっている。固定価格・固定PPP（2020年の購買力平価）で見た比（青）は、1995年の0.69から2008年の0.66まで下がったあと上昇し、2025年は0.73である。実質で見れば、日本は1995年以降、英国との差をわずかに縮めている。

二つの比が1995年に大きく違うのは、同じ1995年の生産を、どの年の価格で評価しているかが違うからである。赤の系列は1995年の生産を1995年の各国の価格と購買力平価で評価しており、青の系列は2020年の価格と購買力平価で評価し直している。前者では日本は英国の0.82倍、後者では0.69倍になる。両者は2020年に一致する。

つまり、当年価格・当年PPPの比が0.82から0.72に下がったことは、日本の実質の生産性が英国より伸びなかったことを意味しない。この期間に日本のGDPデフレーターは2010年代前半まで下がったあと持ち直し、30年間でほぼ横ばいだったのに対し、英国のデフレーターは大きく上がった。各国のデフレーターの動きと、購買力平価の改定を含む動きとが一致しないため、当年価格の比較では、年ごとに日英の生産物の評価の仕方が変わる。当年価格・当年PPPの系列は、ある年の国どうしの水準を比べるためのものであり、時系列での伸びを比べるには固定価格・固定PPPの系列を使う必要がある。

ただし、2020年の購買力平価で評価しても、日本の水準は英国の約7割にとどまる。実質の伸びで英国を上回ったといっても、水準の差を埋めるほどではない。

## まとめ

- ドル建て名目GDPの日英逆転は、主に円の実質的な減価と人口動態を反映したものである。購買力平価で見れば、日本の経済規模は英国の約1.5倍ある。
- 時間当たり労働生産性の水準では、日本はG7で最も低く、英国の約7割である。
- 実質の伸びでは、1995年以降の日本は英国を上回っており、G7でも米国に次ぐ。英国の伸びは2008年以降停滞している。
- 当年価格・当年PPPで見た日英の差の拡大は、実質の伸びの差ではなく、価格の評価の違いによるものである。生産性の推移を国どうしで比べるときは、どの系列を使っているかを確かめる必要がある。

日本の課題は、実質の生産性が伸びないことよりも、生産したものの価格が上がらず、それが名目の付加価値と賃金の伸びの低さにつながってきたことにある。この点は、同じリポジトリの「[実質円安の正体は「賃金」だった](https://github.com/p72/note-draft/blob/main/実質円安と賃金/01_実質円安の正体は賃金だった.md)」の結論とも重なる。

## 注意点

- **IMFの数値は報道経由である**：ドル建て名目GDPと購買力平価換算GDP、実質実効為替レートの値は、IMF「World Economic Outlook」を引用した報道から取った。IMFの2026年10月版の見通しで更新される可能性がある。
- **2020年前後の振れ**：当年価格・当年PPPの比は、2020〜2022年に大きく上下している。コロナ禍での労働時間と生産の動きに加え、購買力平価の年ごとの推計の振れが考えられるが、要因は特定していない。
- **固定PPPの基準年**：固定価格・固定PPPの系列は2020年の購買力平価を基準にしている。基準年を変えると水準の比は変わるが、各国の実質の伸び率は変わらない。
- **時間当たりの限界**：労働時間の統計の作り方は国によって異なる。日本は短時間労働者の増加で1人当たりの労働時間が減っており、時間当たりと1人当たりで評価が変わる。
- **英国の統計の不確実性**：英国では近年、労働力調査の回答率の低下により、就業者数と労働時間の統計の信頼性が問題になっている。2023年以降の英国の値は幅を持って見る必要がある。

- 時間当たり労働生産性：OECD「Productivity Database」（dataflow：OECD.SDD.TPS,DSD_PDB@DF_PDB,2.0、指標 GDPHRS＝就業1時間当たりGDP、全産業、USD_PPP_H）。当年価格・当年PPPは PRICE_BASE=V、固定価格・固定PPPは PRICE_BASE=LR（OECD SDMX API で取得）[https://data-explorer.oecd.org](https://data-explorer.oecd.org)
- 年率の伸びは、固定価格・固定PPPの系列の対数差を年数で割って求めた。
