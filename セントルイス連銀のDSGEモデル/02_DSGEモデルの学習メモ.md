[前回の記事](01_セントルイス連銀のDSGEモデルをPythonで動かした.md)では、セントルイス連銀の DSGE モデル（Faria-e-Castro 2026）を Python に移植した。本稿はその続きとして、移植コードの全体像、移植の精度、インパルス応答（IRF）の読み方、モデルに入っている12の構造ショックを、学習用のメモとして整理する。

## DSGEモデルとは

DSGE（動学的確率的一般均衡）モデルは、家計・企業・中央銀行がそれぞれ将来を見越して最適に行動するという前提で、経済全体を連立方程式で表したモデルである。需要の急減、原油高、予想外の利上げといった「ショック」が起きたとき、GDPや物価がどう動くかをシミュレーションできる。

## 移植コードは3段構え

| 段階 | ファイル | 内容 |
|---|---|---|
| ① モデル本体 | `stlouis_dsge.py` | 論文の均衡条件を98個の変数で書き、線形化して QZ 分解で解く |
| ② 米国の分析 | `hd.py`、`irf_*.png` | インパルス応答と、コアPCEインフレの歴史分解 |
| ③ 日本版 | `jp/` | ESRI・e-Stat・FRED のデータでカルマン平滑化し、コアCPIを要因分解する。`estimate_jp.py` では日本向けにパラメータを推定し直す |

日本版では、ゼロ金利期の政策金利を観測から外して「影の金利」として推計し、消費税率を引き上げた四半期は欠損扱いにし、トレンド成長率を日本の平均に合わせている。

モデルで見ると、2023年以降に日本のコアCPIが2%を超えているのは主に**金融要因**（トレンドインフレの上昇と、低金利の据え置き）による。1995〜2012年のデフレは、金融要因と需要の弱さで説明される。ただし米国の推定パラメータをそのまま使った試算では金融要因の寄与が平均+1.9%ポイント、日本向けに推定し直すと+1.2%ポイントに縮む。形を見るための試算と位置づけるのがよい。

## 移植の精度

数値計算の面は、ほぼ機械精度で合っている。

- 定常状態の残差は 1e-16
- ヤコビアンは複素ステップ微分で求めており、機械精度
- QZ 解の残差は 5e-12。Blanchard–Kahn 条件（安定根の数＝98）も満たす

論文の付録Dの IRF とピーク値を比べると、12ショック中10ショックでよく合う。

| 再現度 | ショック |
|---|---|
| ◎ ほぼ一致 | インフレ目標、原油供給、限界効用、コンビニエンス・イールド、政府消費、移転支出、価格マークアップ |
| ○ 少しずれる | 金融政策（GDPのインパクトが論文0.3、Python 0.67）、投資の限界効率、賃金マークアップ |
| △ ずれが大きい | TFP成長率（論文4.0、Python 2.54）、労働不効用（論文2.6、Python 2.14） |

ずれが大きいのは、恒久的なトレンドを動かす2つのショックだけである。論文に書かれていない実装の細部（賃金フィリップス曲線のトレンド調整、Dynare での変数のタイミングなど）が違うためと考えられるが、原典のコードが公開されていないので確かめられない。比較値は図から目で読み取ったものなので、小数点以下の差より、符号と形が合っているかが重要である。

## IRF（インパルス応答関数）とは

IRF は、経済に1回だけショックを与えたとき、各変数がどう反応し、どう元に戻っていくかを時間を追って描いたものである。鐘を1回叩くと音が鳴り、だんだん小さくなっていく。叩くのがショック、音の鳴り方が経済変数の動きにあたる。

予想外の利上げ（金融政策ショック）を例にとると、次のように動く。

| 時点 | 起きること |
|---|---|
| 0期 | 政策金利が上がる |
| 1〜4期 | 借入コストが上がり、投資と消費が減って GDP 成長率が下がる |
| 数四半期後 | 需要が弱まり、インフレ率がじわじわ下がる |
| 長期 | ショックが消え、定常状態に戻る |

読み方のポイントは次のとおりである。

- **縦軸**：移植コードでは水準で描いている（たとえば定常状態のFF金利は3.84%）
- **横軸**：ショックからの経過四半期
- **ショックの大きさ**：ふつうは1標準偏差（そのショックの典型的な大きさ）
- **見るところ**：符号（上がるか下がるか）、ピークの大きさ、ピークのタイミング、戻る速さの4つ

移植コードの `irf_group1〜4.png` に12ショックの IRF、`irf_gap_rstar.png` に産出ギャップと自然利子率 r* の IRF が入っている。上の精度比較は、この IRF のピーク値を比べたものである。

## 12の構造ショック

構造ショックは「経済を揺らす原因」のリストである。経済的な性格で分けると次のようになる。

| 性格 | ショック | 内容 |
|---|---|---|
| 金融 | ① 金融政策 | 中央銀行がルールから外れて予想外に金利を動かす |
| 金融 | ② インフレ目標 | 中央銀行が目指すトレンドインフレ率そのものが変わる（持続性が高い） |
| 需要 | ③ 限界効用 | 家計が今たくさん使いたい／節約したいと考えるようになる（選好ショック） |
| 需要 | ④ コンビニエンス・イールド | 安全な国債を持ちたい気持ちが強まる（安全資産への逃避） |
| 投資 | ⑤ 投資の限界効率 | 投資が資本になる効率が変わる。金融の目詰まりなどがここに現れる |
| 財政 | ⑥ 政府消費 | 政府の支出が増減する |
| 財政 | ⑦ 移転支出 | 給付金や補助金など、家計への移転が変わる |
| 供給 | ⑧ 価格マークアップ | 企業の値上げ力が変わる（コストプッシュ） |
| 供給 | ⑨ 賃金マークアップ | 労働者の賃上げ交渉力が変わる |
| 原油 | ⑩ 原油供給 | 原油の量や価格が動く（OPECの減産など） |
| 供給 | ⑪ 労働不効用 | 働きたい気持ちが変わる。恒久ショック |
| 供給 | ⑫ TFP成長率 | 技術進歩のスピードが変わる。恒久ショック |

⑪と⑫は経済のトレンドそのものをずらす恒久ショックで、IRF の再現のずれが大きかったのはこの2つである。

需要ショックと供給ショックは、GDPとインフレの動く向きで見分けられる。需要ショックでは両者が同じ向きに動き、供給ショックでは逆向きに動く（GDPが下がって物価が上がる、など）。

### 歴史分解のグループ分け

歴史分解のグラフでは、12ショックにコロナ期だけ有効な3つの特殊ショックを加えた15ショックを、5つのグループにまとめて色分けしている（`hd.py` の `GROUPS`）。上の表の「性格」とは少し違うので注意が要る。

| グループ | 含まれるショック |
|---|---|
| 供給 | TFP成長率、労働不効用、**投資の限界効率**、価格マークアップ、賃金マークアップ、COVID労働供給 |
| 需要 | 限界効用、コンビニエンス・イールド、COVID需要 |
| 金融 | 金融政策、インフレ目標 |
| 財政 | 政府消費、移転支出、COVID移転支出 |
| 原油 | 原油供給 |

投資の限界効率ショックは、`hd.py` では「供給」グループに入っている。測定誤差などの残りは「その他」として表示される。

日本版の歴史分解では、2021〜22年のコアCPIの大きなマイナスは供給（主にTFP）と需要に割り振られ、2021年4月の携帯電話通信料の値下げは供給側の要因として現れる。どの個別ショックが効いているかまでは確かめていない。また、モデルは閉鎖経済なので為替・輸入物価の経路がなく、2022〜23年の円安・輸入物価の上昇は供給や金融など別のショックに割り振られる。
