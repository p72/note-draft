# boj_shocks

一方井宏汰・川本卓司・桜健一（2024）「わが国の非伝統的金融政策と為替レート変動」（日本銀行ワーキングペーパー No.24-J-26）の設計を参考に、日本銀行の金融政策決定会合の日の金利ショックと為替への直接ショックを取り出すコード（記事4節のステップB・C）。

論文の仕様：金利ショックは会合の日の日本の金利（3か月物OIS、2・10・30年国債）の前日差（低下がプラス）。直接ショックは、東京9時→17時のドル円の変化を、日米金利差の変化（当日とラグ1）と前日の9時→17時の変化で回帰した残差の、会合の日の値。ローカル・プロジェクション（h=0〜30、Newey-West）で反応を推計。期間は2002年4月〜2023年12月。

本稿の置き換え・仮定：
- 3か月物OISの代わりに1年物（日本：財務省の国債1年、米国：GSWのゼロクーポン1年）。米国の2・10・30年もGSW。米国だけが休みの日（GSWのファイルで空欄）は直前の値を使う
- LPのドル円は東京17時（日本銀行 FXERD04）、9時は FXERD01
- 会合の日：日本銀行「決定事項」の各年の一覧（https://www.boj.or.jp/mopo/mpmdeci/mpr_YYYY/index.htm）にある会合の公表文（k+日付のファイル）の日。2020年3月16日の臨時会合はファイル名の形式が違うため手で追加（299日）
- 会合ごとの反応は h=0〜30。期間への寄与は、LPを h=0〜120 まで推計し、期末までの反応と期首前日までの反応の差を、期首前の会合も含めて合計（120日より先は一定と仮定）。区間は20営業日のブロック・ブートストラップ（200回）

ファイル：
- `boj_shocks.py`：推計（`python3 boj_shocks.py` で論文の期間、`END=2026-11-12` で延長）
- `boj_mpm_dates.csv`：会合の日（公表時刻が書かれているものは時刻つき）
- `boj_events_2023.csv`・`boj_events_2026.csv`：会合ごとのショックと反応（A＝金利ショック、B＝金利＋直接ショック）
- `boj_lp_coef_2023.csv`・`boj_lp_coef_2026.csv`：LPの係数
- `boj_windows_2026.csv`：期間ごとの会合ショックの寄与（90%区間つき）
- `stepC_tokyo_basis.csv`：東京17時・米金利調整後の異常変化を、日銀会合の日・財政ニュースの窓・それ以外の日に分けた集計（記事4c節、日付による集計で、ショックの分解ではない）
